# 🔹 Adwise-AI

نظام بسيط لتحليل إعلانات Google باستخدام الذكاء الاصطناعي.  
المشروع لسه في بدايته، وبنشتغل عليه عشان نطلقه قريب إن شاء الله.

## 🛠 التقنيات
- TypeScript
- Node.js
- Express

## 🚀 إزاي تشغله؟
```bash
git clone https://github.com/hagaaty-create/Adwise-AI
cd Adwise-AI
